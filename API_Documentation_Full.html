🔑 How Authentication Works

Step 1 — Call POST /api/auth/login with email + password. You get back a token (JWT).

Step 2 — Include it in every protected request header:
Authorization: Bearer <your-token>

SignalR hubs — Pass the token via query string when connecting:
https://localhost:5263/notificationhub?access_token=<your-token>

Roles: Admin · Journalist · Organization · User

📡 Real-time SignalR Hubs

Two hubs run alongside the REST API. Connect with the SignalR JS client and pass your JWT via ?access_token=.

NotificationHub
/notificationhub
Client event: ReceiveNotification
Fires when: someone follows you · post approved/rejected · donation received · journalist goes live · account approved/rejected.

Payload: { id, type, message, referenceId, isRead, createdAt }
LiveHub
/livehub
Client events: LiveStarted · LiveEnded
Join a journalist's group to receive live session events in real time. Group name = journalist's user ID.
